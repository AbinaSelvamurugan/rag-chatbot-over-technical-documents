# Contributing

Use Python 3.11 and Node 22. Run `pytest`, `ruff check backend`, and `npm run build` before submitting changes. Changes to prompts, splitting, embeddings or relevance judgments require recorded evaluation runs. Do not commit confidential documents, credentials, third-party documentation without redistribution rights, or generated indexes. Include regression tests with bug fixes. Review PRs changing authentication, source fetch, prompt injection handling and vector metadata carefully.
